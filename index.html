The Mathematics of Q-Learning

1. The Q-Learning Update Rule

Q-learning is an off-policy, model-free Temporal Difference learning algorithm that directly approximates the optimal action-value function Q*:

Q(s, a) ← Q(s, a) + α × [ r + γ × maxa' Q(s', a') − Q(s, a) ]
  • s, a: Current canonical state and chosen action.
  • α (Alpha): Learning rate step size (0 < α ≤ 1).
  • r: Immediate reward observed after taking action a (+1 win, -1 loss, 0 draw).
  • γ (Gamma): Future reward discount factor (0 ≤ γ ≤ 1).
  • maxa' Q(s', a'): Best estimated value in successor state s'. For terminal transitions, this is strictly 0.

2. Exploration vs. Exploitation (ε-Greedy)

With probability ε, the agent enters the exploration branch and selects uniformly at random among legal moves. With probability 1 - ε, the agent exploits its current knowledge and picks argmax_a Q(s,a) with random tie-breaking.

Important Nuance: Choosing the exploration branch does not guarantee picking a non-greedy move! If there are k legal moves, the random draw has a 1/k probability of picking the greedy action anyway: P(greedy) = (1 - ε) + (ε / k).

Dynamic Programming (DP) vs. Q-Learning

Model-Based DP computes values offline using full knowledge of transition probabilities P(s'|s,a) and rewards without stepping in the environment. Model-Free Q-Learning requires zero prior transition model, discovering optimal play directly from trial-and-error gameplay samples.
